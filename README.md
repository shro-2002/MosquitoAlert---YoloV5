# MosquitoAlert - YoloV5

> **Attribution.** `mosquitoalert-yolov5-baseline-submission.ipynb` is the official baseline notebook from the AIcrowd MosquitoAlert Challenge, and `mosquitoalert-yolov5-baseline.pt`, `train.csv`, `test_phase1_v2.csv` and `sample_submission_phase1_v2.csv` come from the challenge. They remain subject to the challenge's own terms; the MIT licence in this repository does not apply to them. `submission_phase1.csv` is a submission file generated with the baseline.

 The competition centred around utilising advanced computer vision techniques to detect and classify small objects. In this challenge, participants will develop cutting-edge AI solutions that precisely identify mosquitoes within images captured by citizen contributors using their mobile devices.
